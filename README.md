# my-portfolio

Portfolio website of **Chibueze Wisdom Ugochukwu**, UI/UX & Product Designer and Full-Stack Developer.

## Pages

- `index.html` – home: about, selected work, skills, design process, experience, contact
- `dominion-city-kubwa.html` – case study: church & community engagement app
- `delivery-hub.html` – case study: delivery app onboarding
- `resume.html` – résumé, with a PDF download (`assets/Chibueze-Ugochukwu-CV.pdf`)

Plain HTML, CSS and a little vanilla JavaScript. No build step.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

Repository **Settings → Pages → Build and deployment**: Source "Deploy from a branch", Branch `main`, folder `/ (root)`.
The site will be served at `https://gentle382.github.io/my-portfolio/`.
